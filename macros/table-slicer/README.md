# テーブル用スライサー連動マクロ

`Sheet3.cls` は、ピボットテーブル「ピボットテーブル1」のスライサー（`加工担当者` / `加工機械`）の選択状態を、
シート「プロジェクトのスケジュール」上のテーブル「データ範囲」のオートフィルタへ反映するマクロです。

`Module2.bas` は列の表示/非表示や画面固定などのシート操作マクロに加え、テーブルのオートフィルタを
解除する `フィルタクリア` を含みます。`フィルタクリア` はテーブルのフィルタ解除と合わせて、
そのテーブルをデータソースとするピボットテーブルのスライサー選択も全解除するよう拡張しています。

## 動作概要（Sheet3.cls）

- `Worksheet_PivotTableUpdate` がピボットテーブル更新時に発火し、対象フィールドごとに `スライサー連動反映` を呼び出す。
- `スライサー連動反映` は指定フィールドの表示中アイテムを収集し、
  - 全選択 または 全解除（表示件数0）の場合はテーブルのオートフィルタを解除
  - それ以外は表示中アイテムの値で `AutoFilter(Criteria1:=arr, Operator:=xlFilterValues)` を適用
- `Application.EnableEvents` を退避・無効化してから処理し、完了後に元へ戻すことでイベントの再発火を防止。

## 動作概要（Module2.bas の フィルタクリア）

- アクティブシート上の各テーブル（ListObject）についてオートフィルタが適用中なら `ShowAllData` で解除する。
- 続けて `テーブル連動スライサークリア` を呼び出し、そのテーブルを `SourceData` とするピボットテーブルを
  ワークブック内の全シートから探索。該当ピボットテーブルに紐づく `SlicerCache` を見つけたら
  `ClearManualFilter` で選択状態を全アイテム選択（フィルタなし）へリセットする。
- これにより、テーブル側のフィルタ解除とスライサーの選択状態が食い違わなくなる
  （スライサー側が一部選択のまま残る、という不整合を防ぐ）。

## Excelへの取り込み方法

Shift-JIS 環境の VBA プロジェクトへ取り込む場合は、VBEで対象シートのコードモジュールとして貼り付けるか、
`.cls`/`.bas` として `Application.VBE` からインポートしてください（元ファイルは Shift-JIS エンコードでした）。
